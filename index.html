SOVEREIGN ENTERPRISE

A company's whole operational layer — tasks, chat, CRM, documents, the books, the one-true-record and the people — running on the employees' own devices, peer to peer. Every write is signed by the device that made it and checked before it is read. No per-seat software. Nothing leaves the building. booting the kernel…

Kernel-backed: this page imports src/crdt · gate · canon · keys · node · vault · books · lease · sim — the same modules the test suite and the mutation witness prove in CI. Each device holds its own Ed25519 key and its own replica; the company is a pure function of the set of signed writes a device holds, so devices that have seen the same writes hold the same company, byte for byte, whatever order the network delivered them in.
